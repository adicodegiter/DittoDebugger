# Code of Conduct

We want a respectful, constructive, and accessible project space. Participants must communicate professionally, welcome differing technical views, give feedback about work rather than people, and avoid harassment, discrimination, personal attacks, and publication of private information.

Project maintainers may remove content or participation that violates these expectations. Report a concern privately through the repository's GitHub security/advisory contact channel or directly to the hackathon organizer. Do not include secrets or sensitive personal details in public issues.
